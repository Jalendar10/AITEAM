# AITEAM

AITEAM is a collection of reusable skills, agents, commands, hooks, and
engineering workflows for AI coding assistants.

## Contents

- `agents/` — specialized coding and review agents
- `skills/` — reusable engineering workflows and guidance
- `commands/` — command shims and developer utilities
- `hooks/` — lifecycle and quality hooks
- `scripts/` — supporting tooling
- `ecc2/` — the Rust control-plane prototype

Review the files in this repository before enabling hooks or executing scripts
from an untrusted checkout.
